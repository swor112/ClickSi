# Click Si

แอปจดบิลและวันหมดอายุ เตือนก่อนถึงวันจ่าย เก็บ QR และเลขบัญชีไว้กับบิล

## เริ่มใช้งาน (สำหรับนักพัฒนา)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20 ขึ้นไป

```bash
npm install      # ติดตั้งเครื่องมือ (ครั้งแรกครั้งเดียว)
npm run dev      # เปิดเว็บสำหรับพัฒนา ที่ http://localhost:5173 แก้ไฟล์แล้วหน้าเว็บอัปเดตเอง
npm run build    # สร้างไฟล์เว็บจริงไว้ในโฟลเดอร์ dist/
npm run format   # จัดรูปแบบโค้ดให้อ่านง่าย
```

## โครงสร้างโปรเจกต์

```
index.html                 หน้า HTML หลัก (โครงเปล่า แอปวาดหน้าจอลงใน #app)
src/
  main.js                  จุดเริ่มต้น: โหลดสไตล์ ตั้งค่า แล้วแสดงหน้าแรก
  router.js                รายชื่อหน้าทั้งหมด (VIEWS) และฟังก์ชัน render()
  state.js                 ค่าที่ใช้ร่วมกันทั้งแอป: ผู้ใช้ที่ล็อกอิน รายการบิล กล่องแจ้งเตือน การตั้งค่า

  pages/                   หน้าจอ หนึ่งไฟล์ต่อหนึ่งหน้า
    auth.js                เข้าสู่ระบบ / สมัครสมาชิก / เปลี่ยนรหัสผ่าน
    home.js                หน้าแรก (การ์ดสรุปเดือน)
    items.js               รายการบิลทั้งหมด
    calendar.js            ปฏิทิน
    item-detail.js         หน้ารายละเอียดบิล + บันทึกการจ่าย
    item-edit.js           เพิ่ม / แก้ไขบิล
    item-look.js           เลือกไอคอนและสีของบิล
    inbox.js               กล่องแจ้งเตือน
    notification-settings.js  ตั้งค่าการแจ้งเตือน
    insights.js            สรุปรายจ่าย
    history.js             ประวัติการจ่าย
    account.js             หน้า "ฉัน" และแพ็กเกจ Pro
    install.js             เพิ่มแอปลงหน้าจอโฮม
    admin/                 หลังบ้าน (ผู้ใช้ แพ็กเกจ เมนู รายการสำเร็จรูป การแจ้งเตือน ประกาศ บันทึกการใช้งาน)

  data/                    ข้อมูลและกฎของแอป
    records.js             อ่าน/บันทึกผู้ใช้และบิล และแปลงข้อมูลจากเวอร์ชันเก่า
    config.js              การตั้งค่าที่แอดมินควบคุม
    derived.js             คำนวณสถานะบิล ยอดรายเดือน วันเงินเดือนเข้า
    reminders.js           ระบบเตือน
    demo.js                บัญชีและข้อมูลตัวอย่าง

  lib/                     เครื่องมือทั่วไป (ไม่ขึ้นกับหน้าจอ)
    store.js               ที่เก็บข้อมูล (ตอนนี้ใช้ localStorage)
    password.js            เข้ารหัสรหัสผ่าน (PBKDF2)
    dates.js               วันที่และจำนวนเงิน
    constants.js           ค่าคงที่ เช่น หมวด ธนาคาร ชื่อเดือนไทย
    icons.js               ไอคอน (Lucide)

  ui/                      ส่วนหน้าจอที่ใช้ร่วมกัน
    dom.js                 toast, sheet, ช่องกรอกผิด
    navigation.js          ไปหน้าถัดไป / ย้อนกลับ / สลับแท็บ
    shared.js              แถวรายการบิล แถบเมนูล่าง
    transitions.js         แอนิเมชันเปลี่ยนหน้า
    sound.js               เสียงเวลากดปุ่ม

  styles/                  CSS แยกตามส่วน (index.css รวมทุกไฟล์ตามลำดับ)
  assets/                  ฟอนต์ LINE Seed Sans TH และไฟล์เสียง

legacy/clicksi-demo.html   ไฟล์เดโมเดิมแบบไฟล์เดียว เก็บไว้ใช้โชว์และเทียบผลลัพธ์
```

## สถานะตอนนี้

- **ขั้นที่ 1 เสร็จแล้ว:** แยกไฟล์เดียวออกเป็นโปรเจกต์ หน้าตาและการทำงานเหมือนเดิมทุกอย่าง
  (ทดสอบโดยรันขั้นตอนเดียวกันกับไฟล์เดิมและเวอร์ชันใหม่ แล้วเทียบข้อความบนจอและภาพหน้าจอ ได้ผลตรงกัน)
- **ยังเก็บข้อมูลในเบราว์เซอร์ (localStorage)** ข้อมูลยังไม่ข้ามเครื่อง ขั้นถัดไปคือต่อฐานข้อมูล Supabase
  โดยเปลี่ยนที่ `src/lib/store.js` และ `src/data/` เป็นหลัก

## ขึ้นเว็บด้วย GitHub Pages

มี workflow ที่ `.github/workflows/deploy.yml` สร้างเว็บและอัปขึ้น GitHub Pages ให้อัตโนมัติทุกครั้งที่ push เข้า `main`
ต้องตั้งค่าครั้งเดียว: **Settings → Pages → Source** เลือก **GitHub Actions**
